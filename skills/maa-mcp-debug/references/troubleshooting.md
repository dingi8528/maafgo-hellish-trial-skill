# 模拟器与 MaaMCP 故障定位

## MuMu 调试准备

使用[MuMu 官方网站](https://mumu.163.com/)，参考[官方 ADB 连接说明](https://mumu.163.com/help/20240807/40912_1073151.html)。各版本设置位置可能变化：在当前模拟器设置/问题诊断或多开管理器读取实际 ADB 状态、端口和安装目录。只建议用户开启所需的 ADB 调试，不要求 root 或管理员启动，也不自行下载未知游戏安装包。

| 现象 | 先检查 | 处理边界 |
|---|---|---|
| 工具列表没有 MaaMCP | 宿主 MCP 启动日志、解释器绝对路径、虚拟环境 | 修复命令与参数，重启该服务；没有工具不能声称已连接 |
| 设备发现为空 | 模拟器确实运行、ADB 调试、MCP 旧会话 | 清理本轮旧控制器后新会话重试一次；仍为空再定位实例自带 adb.exe |
| 指定 ADB 后仍为空 | 随包 `../maafgo-hellish-trial/scripts/maa_mcp_bootstrap.py` 诊断、本机安装路径、实际端口 | 记录响应，必要时让用户在 MXU 连接一次；不猜固定 16384/7555 |
| 已发现但连接失败 | 完整注册设备名、控制器状态、目标实例 | 新会话重新发现；多实例逐个只读截图或请用户选择 |
| `adb.log` 无法写/服务端未启动 | host ADB daemon、临时目录可写性 | 随包 bootstrap 在本轮数据目录内用私有 TEMP 启动缺失的 daemon，已有则复用；不删用户 adb.log、不 kill 所有 ADB |
| 中文路径或参数被截断 | stdio UTF-8、宿主命令参数数组 | 避免交互式 PTY 手敲 JSON；必要时独立 UTF-8 stdin/stdout 客户端 |
| 点击坐标偏移 | 当前截图尺寸、裁图元数据、是否重复缩放 | 纠正坐标映射后验证低风险目标；不固定乘 1.5 |
| OCR 模型缺失 | MaaMCP/项目模型目录、下载日志 | 按官方检查/下载工具处理，先测速并报告体积；不改阈值代替缺模型 |
| Custom Action 未注册/Agent 提前退出 | interface 位置、child_exec、依赖、Agent stderr | 使用实际装依赖解释器；临时 bundle 保留正确相对路径 |
| `override_pipeline` 写入失败 | PipelineParser 原始错误、JSON/schema、重复节点 | 清理资源后最多重试一次，检查所有依赖；不要直接认定缓存故障 |
| `stop_pipeline` 缺 `Tasker.stop()` | MaaMCP/MaaFramework 版本与实际 API | 使用随包 bootstrap 进程内兼容包装，转 `post_stop().wait()`；不改全局包 |
| Result 对象不可 JSON 序列化 | 工具完成状态与实际响应缺失是否分开 | 更新到修复版本或会话内最小兼容适配；无可核验响应时不推断操作失败再点一次 |
| 无茶壶界面却校验失败 | 当前入口/活动是否根本不提供茶壶 | 复用项目通用“无入口则跳过”分支；不为了测试消耗茶壶 |

MuMu 库可能向 stdout 写 `nemu_connect` 等非 JSON 日志。自建 stdio 客户端只把与请求 ID 匹配的有效 JSON 作为响应，旁路文本保留日志；正常有效响应仍可继续。不要只因一条解析警告否认连接成功。

## 识图与状态故障

仓库、编队、助战和指令卡使用不同资源，不交叉套模板。优先检查实际 ROI、裁剪、加载动画、从者形态与 JP 覆盖层。列表操作串行执行“识别→未找到→滑动一次→等待→重新识别”，不同时截图、滑动和点击旧框。目标位于半截行时补扫重叠区域，不降低身份阈值让错人过关。

战斗换人后要确认预期身份已入场；自然退场/候补也如此。主界面按钮命中不是换人完成的充分证据，动态画面变化也不是失败原因。超时提示采用“未能确认换人后的从者，无法继续按目标释放技能；请保留当前画面，检查是否仍在动画或换人未生效”，结合实际诊断给处理步骤，不只报内部字段名。

## 版本与网络

本包不捆绑 MaaMCP/MaaFramework 二进制、不固定“最新”版本。2026-11 历史实战用过 MaaMCP 1.3.0 与 MaaFramework 5.12.3；这只是历史组合，更新后仍需最小连接/截图/停止验证。不要从作者旧绝对路径加载依赖。

GitHub/PyPI 不通时分别检查错误是 DNS、TLS、超时还是本机失效代理。仅在确认代理原因并获得用户网络偏好后，使用本次命令级设置；不要重写全局代理、Hosts 或关闭证书验证。小样本测速失败要报告“无法估算”，给用户手动下载或自行处理网络的选择。
