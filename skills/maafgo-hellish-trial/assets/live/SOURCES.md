# 展示素材来源

- `background.svg`、HTML、CSS和浏览器交互由本技能编写，参考用户提供的“自动地狱试炼”视频工程白紫金版式。
- `bb-loop.webm` 取自该工程已完成的 BB 透明正倒放循环：640×360、30 FPS、约16.43秒、静音，文件约3.06MB。没有复制视频工程里的游戏录屏、账号截图、浏览器配置或私有日志。
- `bb-poster.png` 是用 FFmpeg 的 VP9 透明解码器从上述循环取得的静态图，640×360 RGBA，供暂停动画时展示。
- `scripts/prepare_bb_loop.py` 提供重新生成循环与静态图的便携入口，不包含原工程盘符或作者解释器路径。

BB 角色与原始形象的权利属于原权利人，素材不因随技能提供而改用本仓库的代码许可；本仓库许可适用于自有程序与文档。
