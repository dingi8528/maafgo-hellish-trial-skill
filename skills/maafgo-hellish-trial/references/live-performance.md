# 有画面版：性能评估与验证范围

## 实现前的取舍

最终采用浏览器原生窗口共享的连续 MediaStream，目标30 FPS，可降到15 FPS。视频直接进入本地 `<video>`，不经 Python 图片压缩、HTTP逐帧传输、FFmpeg实时编码或第二个 ADB 连接。后端只读取小型事件状态，BB 使用预制640×360透明循环。

初期曾测低频截图路线：960宽缩放和JPEG编码约5.3ms/张、约100KiB/张。该路线已放弃，**这些数值不能推算或证明连续30 FPS视频的总开销**。代码没有保留自动截图采集或JPEG轮询作为默认展示。

浏览器和窗口采集仍会占用 CPU/GPU、视频表面与内存，不能承诺零开销。需要省资源时可选15 FPS、关闭 BB 动画、降低文字刷新频率，或使用简化版。[窗口共享 API](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia)

## 本机离线浏览器实测

2026-11-15，Windows、32逻辑线程，独立 Chrome headless，视口1920×1080。输入为1280×720、目标30 FPS的动态 Canvas 合成 MediaStream，**没有连接 MuMu，也未实际捕捉系统窗口**；合成视频生成本身也计入浏览器开销。每段预热2秒、采样8秒。

| 场景 | 浏览器CPU（以单核100%计） | 独占内存合计 | 实际呈现FPS | 丢帧 |
|---|---:|---:|---:|---:|
| 页面，未共享、BB静态 | 5.47% | 271.5 MiB | 不适用 | 不适用 |
| 连续合成视频、BB静态 | 25.39% | 295.2 MiB | 30.1 | 0 |
| 连续合成视频、BB循环 | 21.29% | 273.6 MiB | 30.0 | 0 |

短样本受预热、GC、缓存、解码与系统调度影响，不能从第三行低于第二行推断 BB 动画降低负载。按本次视频段看，约占0.21～0.25个CPU核心，在32逻辑线程机器上折算总CPU约0.67%～0.79%；低核心数机器的占比会更高。这不是“叠加到任何游戏都只有这一占用”的保证。

内存使用 psutil 的 USS 合计；额外记录的 RSS 进程合计约744～850MiB可能重复计共享页，不适合直接当作新增私有内存。测试浏览器是独立进程，不代表用户已有浏览器只会新增相同大小；GPU显存未测。

## 已覆盖的行为

- 实际连续 MediaStream 播放、视频时间推进与呈现帧率，不把协商 `getSettings().frameRate` 当作实测值。
- 取消新窗口选择保留旧流；成功换流后释放旧轨道；停止共享、系统ended事件、页面退出清理。
- 改为15 FPS的约束请求保持共享；真实可达FPS以浏览器反馈为准。
- 视频与 JSON 播报独立；后端文案变更进入页面，没有JPEG资源轮询。
- 1920、780、390宽度没有横向页面溢出，游戏画面保持完整比例；停止出帧后提示等待新视频帧，恢复后继续统计，不当作战斗失败。
- 本地真实 HTTP 测试覆盖状态更新、未知任务数量、观察/确认分离、并发写入、资源Range/ETag、拒绝路径穿越与远端Host/Origin、客户端断线后的正常清理。
- 人物循环及静态图可从随包媒体重建，未复制游戏录屏或账号截图到技能。

仍未覆盖：真实 MuMu/其他模拟器在原生窗口选择器中共享、不同GPU或远程桌面、游戏运行时的总CPU/GPU变化、不同浏览器的最小化/遮挡表现，以及网页展示伴随整场试炼的端到端运行。因此不能用上述离线测试宣称真实游戏已经录制或完成。

## 复现测试

运行页面不需要下面的开发依赖；只有自动浏览器验证需要 Chrome/Edge、`websockets`，CPU/内存记录额外用 `psutil`。在隔离环境安装，不替用户修改全局依赖：

```powershell
python -m pip install websockets psutil
python scripts/check_live_view.py --output '本地输出目录' --benchmark-seconds 8
```

脚本创建隔离演示会话，临时覆盖该测试页的共享函数以返回 Canvas MediaStream，不会跳过真实用户的系统共享权限，也不会读取任何模拟器。完成后清理浏览器、轨道与本地临时服务，保留 `report.json` 和标明演示的视频页面截图。

真实使用首次选择模拟器后，先短时观察页面分辨率、实测FPS和任务管理器负载；必要时选择15 FPS或静态BB。只做展示诊断，不点击游戏来人为制造性能样本。
